# **Nova Kytheria**



### *A test of Unity 6.0 plus a project I wanted to do for quite some time — so why not doing both?*

### 

### About the Project



##### *Nova Kytheria* is a factory-building and automation game inspired by classics of the genre.  

##### The project explores both the creative possibilities of \*\*Unity 6.0\*\* and the long-term vision of building a unique gameplay experience that blends:



* Futuristic setting with a poetic/abstract identity.  
* Factory and automation mechanics (inspired by \*Factorio\* but with a distinct twist).  
* Cooperative/competitive multiplayer.  
* Resource handling in multiple states: solid, liquid, gaseous.  
* Transportation systems: conveyors, trucks, trains, ships, aircraft.  





### Planned Features



* **Voxel/Low-poly 3D style** for performance and clarity.  
* **Dynamic construction system**: freeform terrain building and structured factory placement.  
* **Multiplayer** with both cooperation and competition.  
* **Scalable world**: expandable zones and crafted equipment.  
* **Advanced resource logistics** (including pallets, containers, and pipelines).  





### Tech Stack



* **Engine:** Unity 6.0  
* **Language:** C#  
* **Core Tools:** Burst Compiler, Job System (DOTS), Profiler  
* **Version Control:** Git + GitHub
